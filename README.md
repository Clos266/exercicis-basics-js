# 🧠 Exercicis bàsics de JavaScript

Aquest repositori conté una col·lecció d'exercicis pràctics per practicar conceptes fonamentals de **JavaScript** modern: funcions de fletxa, callbacks, operadors ternaris, promeses, rest/spread i manipulació d'arrays.

🔗 **Repositori GitHub**:  
[![Clona aquest repo](https://img.shields.io/badge/Clona%20aquest%20repo-%F0%9F%94%97-blue?style=for-the-badge)](https://github.com/Clos266/exercicis-basics-js.git)

---

## ✍️ Contingut dels exercicis

### 🟦 Nivell 1-3: Arrow Functions

- Convertir funcions tradicionals a funcions de fletxa
- Funcions sense paràmetres
- Ús de `this` dins de classes amb funcions de fletxa

### ⚖️ Operador ternari

- Comparacions bàsiques i avançades
- Ternaris en bucles i funcions

### 🔁 Callbacks

- Funcions amb callbacks simples i asíncrons
- Processament d'arrays i cadenes

### 📦 Rest & Spread

- Combinar arrays i objectes
- Destructuring i paràmetres variables

### 🔄 Transformacions d’Array

- `map`, `filter`, `find`, `reduce`, `every`, `some`

### 🔃 Bucle sobre Arrays i Objectes

- `forEach`, `for-of`, `for-in`, amb i sense index
- Control de flux amb `break`

### ⏳ Promises i Async/Await

- Crear i gestionar promeses
- Async/await amb `try/catch`
- `Promise.all` per múltiples promeses
